# Search for Lyra 01: The Ash Awakening 0.1.0-beta.1

The first Search for Lyra one-shot is available in system-neutral, D&D 5e, PF1, and WFRP4e editions.

Choose exactly one ZIP matching the game system used by your Foundry world. Each archive is a complete standalone module with its own compendiums and assets.

This is a public prerelease for installation testing. Please report the Foundry version, game-system version, selected edition, and exact steps for any problem through the Lisa's Dungeon support channels.

Manual runtime verification and Odinn's sign-off remain open.
