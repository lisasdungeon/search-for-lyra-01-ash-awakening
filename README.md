# Search for Lyra 01: The Ash Awakening

The Ash Awakening is the first one-shot in Lisa's Dungeon's Search for Lyra series for Foundry VTT.

The characters awaken inside a sealed manor, confront stolen memories, uncover the first evidence of Lyra's disappearance, and choose what they are willing to carry into the search ahead. The adventure can be played as a standalone one-shot or as the opening chapter of the nine-part campaign.

## Included editions

- System-neutral Foundry VTT edition
- D&D 5e 5.3.3 edition for Foundry VTT 14
- PF1 11.11 edition for Foundry VTT 12 or 13
- WFRP4e 9.6.4 edition for Foundry VTT 13 or 14, requiring warhammer-lib 2.10 or newer

## Installation

Download the ZIP for your chosen edition from the GitHub release page. Extract it into Foundry's `Data/modules` directory, restart Foundry, and enable the module in a clean world using the matching game system.

Do not install more than one edition in the same world unless you deliberately want separate copies of the adventure.
